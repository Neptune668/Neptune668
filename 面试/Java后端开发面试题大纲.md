# Java 后端开发面试题大纲

> **难度说明**：【初】初级（0~2 年）｜【中】中级（2~5 年）｜【高】高级（5 年+）
> 每类先给出「考察重点」，再列出高频面试题并按难度标注。题目后括号内为高频考察点提示。

---

## 一、Java 基础

### 考察重点
- 面向对象特性、语言基础语法与常用类库
- 值传递机制、异常体系、反射与动态代理
- Java 8+ 新特性（Lambda、Stream、Optional、函数式接口）

### 高频面试题
- 【初】`==` 与 `equals()` 的区别？`hashCode()` 与 `equals()` 的关系？（重写 equals 必须重写 hashCode）
- 【初】String、StringBuilder、StringBuffer 区别？String 为什么不可变？（不可变性的好处）
- 【初】面向对象三大特性？重载（Overload）与重写（Override）的区别？
- 【初】final、finally、finalize 的区别？
- 【初】8 种基本数据类型？装箱/拆箱？Integer 缓存机制（-128~127）？
- 【初】接口与抽象类的区别？Java 8 接口的 default 方法？
- 【中】深拷贝与浅拷贝？如何实现深拷贝？
- 【中】Java 异常体系？受检异常与非受检异常？try-with-resources 原理？
- 【中】反射机制原理与应用场景？JDK 动态代理与 CGLIB 代理的区别？
- 【中】泛型类型擦除？`? extends` 与 `? super` 通配符（PECS 原则）？
- 【中】Lambda 与 Stream 原理？Optional 的用法与意义？
- 【高】Java 只有值传递——如何辨析"传引用"的误区？

## 二、集合与并发

### 考察重点
- 集合框架底层数据结构与实现原理（重点是 HashMap）
- 并发编程核心：线程、锁、volatile、CAS、AQS、线程池
- 并发工具类的使用场景与底层原理

### 高频面试题
- 【初】ArrayList 与 LinkedList 区别？ArrayList 扩容机制（1.5 倍）？
- 【初】HashMap 底层原理？put/get 流程？为什么要引入红黑树（链表转树阈值）？
- 【初】HashMap、Hashtable、ConcurrentHashMap 的区别？
- 【中】HashMap 在 JDK 1.7 头插法导致的多线程死循环问题？
- 【中】ConcurrentHashMap 1.7（分段锁）与 1.8（CAS + synchronized）实现区别？
- 【中】线程的生命周期？创建线程的几种方式？
- 【中】synchronized 原理？锁升级过程（偏向锁→轻量级锁→重量级锁）？
- 【中】volatile 原理（可见性、有序性）？与 synchronized 的区别？
- 【中】CAS 原理？ABA 问题及解决（版本号）？原子类？
- 【中】AQS 原理？ReentrantLock 与 synchronized 的区别（公平/非公平）？
- 【中】线程池核心参数？执行流程？拒绝策略？如何合理设置线程数（CPU/IO 密集型）？
- 【中】ThreadLocal 原理？内存泄漏的原因与预防？
- 【高】CountDownLatch、CyclicBarrier、Semaphore 的区别与场景？
- 【高】阻塞队列原理？ArrayBlockingQueue 与 LinkedBlockingQueue 区别？

## 三、JVM

### 考察重点
- 内存区域划分、对象创建过程
- 垃圾回收机制（算法、收集器、调优）
- 类加载机制与双亲委派
- 线上故障排查（OOM、CPU 飙高、内存泄漏）

### 高频面试题
- 【初】JVM 内存区域划分？哪些线程私有（栈、程序计数器）、哪些共享（堆、方法区）？
- 【初】对象的创建过程？对象在内存中的布局（对象头、实例数据、对齐填充）？
- 【中】判断对象死亡的算法？可达性分析？GC Roots 有哪些？
- 【中】垃圾回收算法：标记-清除、复制、标记-整理各自的优缺点？
- 【中】常见垃圾收集器：CMS、G1、ZGC 的特点与适用场景？
- 【中】类加载过程（加载、验证、准备、解析、初始化）？双亲委派模型？
- 【中】为什么要打破双亲委派？如何打破（自定义 ClassLoader、SPI、Tomcat）？
- 【中】JVM 常用参数（-Xms/-Xmx/-Xmn）？如何查看与解读 GC 日志？
- 【高】线上 OOM 如何排查？堆溢出（OutOfMemoryError）与栈溢出（StackOverflowError）区别？
- 【高】CPU 使用率飙高如何定位（top + jstack + 线程转储分析）？
- 【高】G1 收集器原理（Region、Remembered Set、可预测停顿）？
- 【高】内存泄漏如何排查？常见内存泄漏场景（静态集合、未关闭资源、ThreadLocal）？

- 【中】MVCC 原理？undo log 与 ReadView 机制？

- 【高】分库分表？水平拆分与垂直拆分？分片键如何设计？

## 附：面试准备建议

1. **按难度分层准备**：初级重点掌握基础与框架使用；中级深入原理（HashMap、JVM、事务、缓存）；高级侧重分布式架构设计与故障排查。
2. **每个知识点都要能"说原理 + 讲场景 + 手写核心代码"**，例如 HashMap 扩容、线程池参数、单例模式要能现场手写。
3. **结合项目经验**：把每个知识点落到你实际做过的项目上（"我在 XX 项目中用 Redis 解决了 XX 问题"），比背八股更有效。
4. **优先级排序**：Java 基础/集合并发/JVM → 数据库/Redis/MQ → Spring/微服务 → 网络/OS/设计模式。
