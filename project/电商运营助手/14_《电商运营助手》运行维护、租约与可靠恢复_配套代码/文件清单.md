## 使用要点

1. 服务类文件（agent_runs / agent_workflows / outbox / agent_maintenance）直接覆盖工程同名文件；它们依赖前面章节已就绪的合同、图、检查点与租约服务，不要回退这些前置模块。

2. `worker/tasks.py` 与 `celery_app.py` 是一组关联更新，两个文件均保存后再启动 Worker。

3. `main.py` 在前序业务、登录、模型设置与静态素材基础上新增两个 Agent 路由；路径前缀保持 `/api/v1`，不要改动前序路由挂载。
