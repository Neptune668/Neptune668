# 第20章配套代码清单

按正文顺序开发，下表是完整核对副本。全部为新建文件，正文只给出增量片段，写完一步追加一步；需要核对最终结果时按路径打开同名文件。测试只在本章依赖齐备后运行。

| 文件 | 本篇职责 | 操作 |
|---|---|---|
| `api/app/services/agent_leases.py` | 执行租约：产生执行者标识、校验租约是否有效、长耗时调用期间独立续租 | 创建 |
| `api/app/agents/tool_gateway.py` | 工具网关：工具名翻译成业务服务调用，调用前复核租户、角色、审批、租约与幂等记录 | 创建 |
| `api/app/agents/specialists.py` | 专业节点：诊断、创意与质量三个角色，模型不可用时规则兜底 | 创建 |
| `api/app/agents/persistence.py` | 检查点连接：把 PostgreSQL 检查点封装成上下文管理器 | 创建 |
| `api/app/agents/graph.py` | 商品诊断与优化基础图：七个节点、质量返修环与人工审核暂停 | 创建 |
| `api/app/agents/platform_graph.py` | 通用平台图：五个固定节点加上按注册表循环生成的专业节点 | 创建 |
| `api/app/agents/evaluation.py` | 评估读取器：读取固定用例文件，生成平台边界场景目录 | 创建 |
| `api/evals/product_operation_cases.json` | 固定评估用例数据 | 创建 |
| `api/tests/test_agent_workflow.py` | 图流程测试：暂停、返修、三种恢复决定与观测边界 | 创建 |
| `api/tests/test_agent_components.py` | 组件测试：模块可导入、检查点读取的是配置里的连接串 | 创建 |

使用要点：

- 目录内的路径与工程路径一致，核对时按同名路径覆盖即可，不要改动其他文件；
- 图流程测试使用内存检查点，不依赖 PostgreSQL，`persistence.py` 的验证由组件测试完成；
- 测试命令是累计执行，会带上此前已有的测试文件，预期二十项通过。
