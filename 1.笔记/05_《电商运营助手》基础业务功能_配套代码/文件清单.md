# 05 课件配套代码清单

> 本目录是《05 电商运营助手基础业务功能》课件的配套代码。包内路径与课堂项目目标路径一致：把 `api/app/...` 下的文件复制到课堂项目 `api/app/...` 的同一位置即可。
>
> 同名业务文件在备份后整体替换，不是把内容追加到旧文件末尾。

## 三、数据合同与应用入口

| 目标路径 | 行数 | 职责 |
|---|---:|---|
| `api/app/schemas.py` | 1298 | 接口输入与输出的数据合同，随业务增长逐步扩展 |
| `api/app/main.py` | 24 | 应用入口，本篇只注册基础业务路由 |

`main.py` 为本篇的基础业务版本，只注册 `health`、`auth`、`products`、`promotion_links`、`stores`、`users`、`workspace` 七个路由，不注册 Agent 与模型设置入口。

## 五、不在本包内、沿用既有产出的文件

| 文件 | 来源 | 说明 |
|---|---|---|
| `api/app/models.py` | 课件四产出 | 36 个 ORM 模型，本篇不覆盖 |
| `api/app/core/config.py` | 课件三产出 | 配置中心，本篇不覆盖 |
| `api/app/db/base.py`、`session.py` | 课件三产出 | 数据库会话，本篇不覆盖 |
| `api/.env`、`api/alembic.ini`、迁移版本 | 课堂既有 | 必须保留，不从本包覆盖 |
| Docker 数据卷 | 课堂既有 | 不在本包内 |

## 六、复制后自检

1. `api/app/main.py` 注册的是基础业务七个路由，没有出现 Agent 或模型设置入口。
2. `api/app/schemas.py`、`api/app/services/`、`api/app/api/routes/` 三处文件齐全，没有缺失导致导入失败。
3. 课堂项目的 `models.py`、`.env`、迁移记录仍然是自己的版本，没有被覆盖。
