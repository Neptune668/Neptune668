# 第15章配套代码清单

本目录保存第15章“商品诊断与结构化业务生成”的服务、路由及自动化测试。服务使用项目对应实现；路由以第03篇为基础，仅替换本章七个占位接口，代表第15章结束时的完整文件。

| 文件 | 本章用途 |
|---|---|
| `api/app/services/diagnosis.py` | 商品诊断、模型 JSON 校验与规则回退 |
| `api/app/services/creative_plans.py` | 主图方案与视频脚本生成 |
| `api/app/services/inventory.py` | 第03篇已接入，本章保留供核对，无需重复复制 |
| `api/app/services/inventory_advice.py` | 店铺库存建议 |
| `api/app/services/review.py` | 指标计算和自动复盘 |
| `api/app/services/ad_recommendations.py` | 投放建议 |
| `api/app/services/ad_experiments.py` | 规则生成投放实验草稿 |
| `api/app/services/ad_experiment_stats.py` | 第03篇已接入，本章保留供核对，无需重复复制 |
| `api/tests/` | 各服务的单元与回归测试 |
| `api/app/api/routes/products.py` | 15.7.1～15.7.7：补充服务导入，替换六个商品生成占位接口 |
| `api/app/api/routes/stores.py` | 15.7.8：补充库存建议导入，替换店铺库存建议占位接口 |
| `api/tests/test_stage15_routes.py` | 15.8.1：七个接口的注册、鉴权、真实服务回退及结果保存测试 |

正文15.7逐项给出所需导入和完整路由函数。请替换既有的501占位函数，不要重复追加同路径接口。本目录的两个路由完整文件用于最终核对；自行修改过业务代码时，优先按正文增量修改。图片、视频及异步任务接口仍保留第03篇的占位实现，留待后续章节接入。

第03篇已经注册商品和店铺路由，本章无需修改 `main.py`；应保留第14章已注册的模型配置路由。测试使用既有的 `tests/conftest.py` 设置隔离环境，不需要真实模型 Key，不会连接课堂 MySQL。
