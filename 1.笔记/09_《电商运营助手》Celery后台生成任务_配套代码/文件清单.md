# 第17章配套代码清单

本目录保存后台媒体生成任务的第一阶段代码。正文中包含完整代码，并按状态机、调度和 Worker 的依赖顺序说明。

| 文件 | 本章职责 |
|---|---|
| `api/app/services/generation_jobs.py` | 创建、执行、重试、取消、超时处理和事件记录 |
| `api/app/worker/celery_app.py` | 只注册生成任务的最小 Celery 应用 |
| `api/app/worker/tasks.py` | 将 Celery 消息转给生成任务服务 |
| `api/tests/test_generation_jobs.py` | 任务状态、超时与 inline/Celery 调度测试 |
| `api/app/api/routes/products.py` | 保留第15章业务，替换生成图片、生成视频、重试、取消四个占位接口 |
| `api/app/worker/generation_scheduler.py` | 扫描到期pending任务，接入inline/Celery自动重试 |
| `api/tests/test_generation_scheduler.py` | 到期重试闭环、重复消息、取消跳过及路由接入测试 |

17.5给出完整路由增量；无需覆盖main.py。17.6.3给出独立调度器完整代码，17.8.2说明其启动和模式切换。后续章节继续保留generation_scheduler.py；它调用服务调度入口，无需改写Agent任务文件。本章并未自动启用running任务超时回收。

第05篇会在 `celery_app.py` 与 `tasks.py` 的现有内容后增量增加 Agent、Outbox 和运行维护任务；本章不要提前写入这些未来依赖。
