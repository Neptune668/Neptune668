# 第16章配套代码清单

本目录保存图片、视频与生成素材管理的完整服务代码及测试。正文按依赖顺序讲解并内嵌完整代码，以下文件用于完成后逐行核对。

| 文件 | 本章职责 |
|---|---|
| `api/app/core/config.py` | 完整配置类，统一即梦文生图3.0与视频3.0默认值 |
| `api/.env.example` | 完整环境变量模板，保留已有基础配置并替换媒体配置 |
| `api/tests/test_jimeng_contracts.py` | 即梦提交与查询参数、时长限制及错误响应测试 |
| `api/app/services/volcengine.py` | 火山/即梦类接口的访问密钥解析和签名请求头 |
| `api/app/services/image_generation.py` | 图片任务提交、轮询、下载与本地 URL 返回 |
| `api/app/services/video_generation.py` | 视频任务提交、轮询、下载与工作流元数据 |
| `api/app/services/generated_assets.py` | 生成结果入素材库及按 URL 去重 |
| `api/tests/test_video_generation.py` | 视频提示词和工作流字段测试 |
| `api/tests/test_generated_assets.py` | 素材审核字段与素材关联测试 |

`GenerationJob` 的创建、入队、重试、取消和 Worker 执行属于第17章；本章只说明媒体服务如何返回一个可保存的素材结果。
